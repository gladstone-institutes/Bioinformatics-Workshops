Part 2: Alignment and Quantification

Introduction to RNA-seq Data Analysis Workshop
Gladstone Institutes Bioinformatics Core

Workshop date: September 28-29, 2026

Goals

  1. Build a genome index for the aligner
  2. Align trimmed reads to the human chromosome 16 reference
  3. Generate a gene count matrix with featureCounts

Before you start

  • Docker Desktop is running
  • You completed Part 1: Quality Control (trimmed reads exist in trimmed_reads/)

Aligner by operating system

OS Aligner Why
Mac (Intel or Apple Silicon) STAR Fast splice-aware aligner, widely used for RNA-seq
Linux STAR Same as above
Windows HISAT2 Lighter memory footprint, works well in Docker on Windows

Follow the section for your OS when you see “Mac/Linux” or “Windows” headings.

Step 1: Launch the Docker container

Use the same folder path as Part 1, but with a new container name.

Mac (Apple Silicon, M1/M2/M3/M4):

docker run --platform linux/amd64 --name rnaseq_day2 \
  -v ~/Downloads/Fall_2026_IntroRNAseq_handson_Session_I-II:/data \
  -it nfcore/rnaseq bash

Mac (Intel) / Linux:

docker run --name rnaseq_day2 \
  -v ~/Downloads/Fall_2026_IntroRNAseq_handson_Session_I-II:/data \
  -it nfcore/rnaseq bash

Windows (Command Prompt):

docker run --name rnaseq_day2 -v C:\Users\YourName\Downloads\Fall_2026_IntroRNAseq_handson_Session_I-II:/data -it nfcore/rnaseq bash

Step 2: Verify Part 1 outputs

cd /data
ls -lh trimmed_reads/

You should see 4 trimmed FASTQ files and 2 log files from Part 1.

Step 3: Build the genome index

The aligner needs a pre-built index of the reference genome. This step only needs to be done once per reference genome.

Mac / Linux: build STAR index

mkdir -p star_index
STAR \
  --runMode genomeGenerate \
  --genomeDir star_index \
  --genomeFastaFiles reference_genome/chr16.fa \
  --sjdbGTFfile reference_genome/chr16.gtf \
  --sjdbOverhang 62 \
  --genomeSAindexNbases 10 \
  --runThreadN 2
Parameter Meaning
--runMode genomeGenerate Build index mode (not alignment)
--genomeDir Output directory for the index
--genomeFastaFiles Reference genome FASTA file
--sjdbGTFfile Gene annotations for splice junction detection
--sjdbOverhang 62 Read length minus 1 (our reads are 63 bp)
--genomeSAindexNbases 10 Adjusted for the small size of chr16
--runThreadN 2 Use 2 CPU threads

This takes approximately 5-10 minutes.

Windows: build HISAT2 index

mkdir -p hisat2_index
hisat2-build \
  reference_genome/chr16.fa \
  hisat2_index/chr16
Parameter Meaning
First argument Reference genome FASTA file
Second argument Base name (prefix) for the index files

This takes approximately 2-5 minutes. It creates several files named chr16.*.ht2 in the hisat2_index/ directory.

Step 4: Align reads

Mac / Linux: align with STAR

mkdir -p aligned_reads

Sample 1: Dexamethasone-treated

STAR \
  --genomeDir star_index \
  --readFilesIn trimmed_reads/N61311_dex_R1_trimmed.fastq.gz \
                trimmed_reads/N61311_dex_R2_trimmed.fastq.gz \
  --readFilesCommand zcat \
  --outFileNamePrefix aligned_reads/N61311_dex_ \
  --quantMode GeneCounts \
  --runThreadN 2

Sample 2: Untreated control

STAR \
  --genomeDir star_index \
  --readFilesIn trimmed_reads/N61311_untrt_R1_trimmed.fastq.gz \
                trimmed_reads/N61311_untrt_R2_trimmed.fastq.gz \
  --readFilesCommand zcat \
  --outFileNamePrefix aligned_reads/N61311_untrt_ \
  --quantMode GeneCounts \
  --runThreadN 2
Parameter Meaning
--genomeDir Path to the index built in Step 3
--readFilesIn Paired input files: R1 then R2
--readFilesCommand zcat Decompress gzipped FASTQ files on the fly
--outFileNamePrefix Prefix for all output files
--quantMode GeneCounts Also count reads per gene
--runThreadN 2 Use 2 CPU threads

STAR outputs per sample:

  • *_Aligned.out.sam: Aligned reads in SAM format
  • *_Log.final.out: Alignment statistics summary
  • *_ReadsPerGene.out.tab: Gene-level read counts

Windows: align with HISAT2

mkdir -p aligned_reads

Sample 1: Dexamethasone-treated

hisat2 \
  -x hisat2_index/chr16 \
  -1 trimmed_reads/N61311_dex_R1_trimmed.fastq.gz \
  -2 trimmed_reads/N61311_dex_R2_trimmed.fastq.gz \
  --summary-file aligned_reads/N61311_dex_hisat2_summary.txt \
  -S aligned_reads/N61311_dex.sam \
  -p 2

Sample 2: Untreated control

hisat2 \
  -x hisat2_index/chr16 \
  -1 trimmed_reads/N61311_untrt_R1_trimmed.fastq.gz \
  -2 trimmed_reads/N61311_untrt_R2_trimmed.fastq.gz \
  --summary-file aligned_reads/N61311_untrt_hisat2_summary.txt \
  -S aligned_reads/N61311_untrt.sam \
  -p 2
Parameter Meaning
-x Path to the index base name
-1 Read 1 (forward) FASTQ file
-2 Read 2 (reverse) FASTQ file
--summary-file Save alignment statistics to this file
-S Output SAM file path
-p 2 Use 2 CPU threads

HISAT2 outputs per sample:

  • *.sam: Aligned reads in SAM format
  • *_hisat2_summary.txt: Alignment statistics summary

Step 5: Check alignment statistics

Mac / Linux (STAR):

grep "Uniquely mapped reads %" aligned_reads/N61311_dex_Log.final.out
grep "Uniquely mapped reads %" aligned_reads/N61311_untrt_Log.final.out

Windows (HISAT2):

cat aligned_reads/N61311_dex_hisat2_summary.txt
cat aligned_reads/N61311_untrt_hisat2_summary.txt

What to expect: A good RNA-seq alignment typically shows >80% uniquely mapped reads. Since we are aligning to chromosome 16 only (not the whole genome), your rates may differ from a full genome alignment.

Step 6: Generate count matrix with featureCounts

featureCounts counts how many reads map to each gene. This produces the count matrix needed for downstream differential expression analysis.

Mac / Linux (using STAR SAM files):

mkdir -p feature_counts
featureCounts \
  -p \
  -t exon \
  -g gene_id \
  -a reference_genome/chr16.gtf \
  -o feature_counts/gene_counts.txt \
  aligned_reads/N61311_dex_Aligned.out.sam \
  aligned_reads/N61311_untrt_Aligned.out.sam

Windows (using HISAT2 SAM files):

mkdir -p feature_counts
featureCounts \
  -p \
  -t exon \
  -g gene_id \
  -a reference_genome/chr16.gtf \
  -o feature_counts/gene_counts.txt \
  aligned_reads/N61311_dex.sam \
  aligned_reads/N61311_untrt.sam
Parameter Meaning
-p Paired-end mode (count fragments, not individual reads)
-t exon Count reads that overlap exon features
-g gene_id Group counts by gene_id attribute in the GTF
-a Gene annotation file (GTF format)
-o Output file
Last arguments Input SAM files (one per sample)

featureCounts outputs:

  • gene_counts.txt: Full output with gene info and counts
  • gene_counts.txt.summary: Summary of assigned/unassigned reads

Step 7: Create a clean count matrix

The raw featureCounts output includes extra columns. Extract just the gene IDs and count columns:

tail -n +2 feature_counts/gene_counts.txt | cut -f1,7,8 > feature_counts/count_matrix.txt

Preview the result:

head feature_counts/count_matrix.txt

You should see a tab-separated file with gene IDs in the first column and read counts for each sample in the remaining columns.

Step 8: Exit the container

exit

All output files are saved in your workshop folder on your computer.
